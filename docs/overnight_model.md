# 夜間一括計算（実機寸法は固定）

PowerShellで次の2行を実行する。

```powershell
git pull
.\.venv\Scripts\python.exe -u overnight_model.py
```

GPUは既定cuda_ad_rgb。逐次実行で複数描画を同時に立ち上げない。総サンプル数は維持し、11GB GPUでのメモリを抑えるため1 spp/passを既定にする。実行中だけWindowsの自動スリープを抑止し、終了時に解除する。画面の消灯は妨げない。PCをシャットダウンしたり蓋を閉じたりした場合の継続動作は保証しない。

## 計算する内容

|段階|評価範囲|計算数|総spp|
|---|---|---:|---:|
|全幅・中央高さ|x=-273〜273 mm、y=0の周辺|552|512|
|中央・左右端の高サンプル|x=0,-250,+250 mm、y=0、seed17|24|1024|
|別シードで再確認|同じ3か所、seed29|24|1024|
|数値座標スケール再確認|中央、scale10000（通常1000）|8|1024|
|phase3のLEDを1本ずつ点灯|配列番号3・7・11・15（0始まり）、中央、2シード|16|1024|
|全幅・上側高さ|x=-273〜273 mm、y=100の周辺|552|512|
|全幅・下側高さ|x=-273〜273 mm、y=-100の周辺|552|512|
|合計||1728||

各照射像は仕切りのみ／仕切り＋マスクを比較。通常の照射像は4位相すべて、19本のLEDの位相ごとの点灯を計算する。光源別比較だけ対象LED1本を発光させるが、他の仕切り・レンズ・実発光長約329 mmなどは維持する。LED幅3 mm、仕切り高さ32 mm・厚さ1.5 mm、LED距離138.13 mm、スクリーン1.5 mm、開口率40%などを変更しない。同位相LED間の空間的な寄与は、光源別データから確認する。

全幅は69タイルに分割、1枚約7.913×0.989 mm、2048×256画素、水平約0.003864 mm/画素。3段の高さではそれぞれ約1 mmの細い帯を高精細に調べる。**312 mmの高さ全体を、この細かさで総当たりする計算ではない。** 全面を微小画素で一括描画せず、画面全幅の位置変化と上下の違いを調べる構成。

高サンプルの局所評価と光源別評価は2×0.25 mm、512×64画素。物理モデルは全画面のまま。各撮影範囲を原点へ移す修正を全段階に適用する。

## 所要時間と容量

実際のRTX2080Tiでこの一式の所要時間は未測定。一晩で終わる保証はない。終了しなくても途中まで保存され、同じコマンドで続きから実行できる。

元NPYは約3.24 GiB、これにPNG、メッシュ、ログ、共有ZIPが加わる。空き容量は15 GB程度以上を推奨。計画のみ確認する場合は`--plan-only`を付ける。

## 中断・失敗・再開

保存先は`results/overnight_v2`。同じコマンドを再実行すると、完了した段階は検査して再利用し、途中の段階は既存NPYを再利用する。物理条件・サンプル数などが違う場合の再開は拒否する。別設定で実行する場合は`--output results/別名`を指定する。

完了した各画像を保存する。中断時点で計算中の1画像は再計算する。段階がエラー終了しても他の段階を続行し、全完了と部分完了を区別して表示する。GPUメモリ不足で自動的に物理寸法・総spp・画素数を減らす処理はない。

`overnight_status.json`に段階の状態、各段階の`.log`に実行ログ、段階フォルダの`progress.json`に画像の進捗が残る。PowerShellの画面にも出力する。

## 翌日共有するファイル

`results/overnight_v2/overnight_summary.zip`を送る。各段階の設定・CSV・比較図・ログ、および局所評価と光源別評価の元NPYを含む。大きな全幅走査の元NPYは共有ZIPに入れず、各段階のフォルダに保持する。

- `suite_summary.csv`：段階・位相・条件ごとの平均照射量と推定幅の中央値。暗い位相や不安定な推定を平均で隠さないよう元CSVも保持。
- `phase3_source_shares.csv`：各LEDが中央の局所照射へ占める割合。左右の目への漏れ率ではない。
- `numerical_sampling_checks.csv`：別シードと数値スケールの平均照射量の差。5%超には要確認フラグ。平均が一致しても像幅・形状まで収束したとは限らない。
- `overnight_status.json`：完了・失敗・中断の判別。ZIPがあることだけで全完了とは判断しない。

照射分布間の重なりは実機LCDクロストークではない。スクリーンの角度依存散乱、LCD応答、実際の左右サブピクセル割当、瞳孔径は描画に含まれていない。まず今回の修正済み光学モデルの結果を評価する。

## 開発時の軽量試験

`--smoke-test --variant scalar_rgb --output results/任意の空フォルダ`は極小画像・1 sppのみ。実行・保存・再開の確認用で、光学評価には使わない。通常の夜間計算では付けない。
