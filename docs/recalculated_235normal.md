# LED間隔23.5mm（直角方向）による設計再計算

**履歴資料：125mm・追加背面アクリルなしの計算です。現在の採用設計は[138.13mm＋背面10mm](accepted_13813_rear10.md)を参照してください。**

2026-11-19。LEDの発光中心同士の直角方向の間隔が23.5mmであるという訂正を反映。端同士の隙間ではない。

## 前提

- バーの傾き：縦:横=3:1。縦から18.434949度。
- LED直角ピッチ23.5mm、水平ピッチ24.771175mm、同位相水平ピッチ99.084700mm。
- 既定：LEDから凸面頂点125mm、凸面頂点からスクリーン1.5mm、受光面はPMMA内。
- レンズピッチ0.7mm（溝に直角）、厚さ2mm、曲率半径0.5mm、屈折率1.49、LED水平幅3mm。
- 追加のレンズ背面アクリルはモデルに含まれない。実機にある場合は距離の換算も再修正が必要。
- ROIは4位相LEDの中央を原点とする水平±23mm、上下±4mm。LED16本、各位相4本。
- 中央4本のy=0水平位置は -37.156763, -12.385588, 12.385588, 37.156763mm。

## 計算式（近軸・頂点近傍）

寸法はmm。c=3/√10、D=125、t=2、n=1.49、s=1.5、p=0.7、LED水平ピッチd=23.5/c。
```text
A = D - t + t/n                 # 物体側の換算距離
Q = s/n                         # PMMA内スクリーンの換算距離
P = p(1 + Q/A)/c                # 水平方向の照射縞周期
Δ = (Q/A)d                      # LEDを1本ずらした時の像中心の移動量の絶対値
目標の位相間隔 = P/4
誤差率 = (4Δ/P - 1) × 100
```
像はLEDの移動と逆向きに移動する。ここでは間隔の絶対値を記載。
これは原点のオフセットとは別の誤差であり、原点合わせだけでは位相間隔は変わらない。

## スクリーン位置の比較（LED→頂点125mm固定）

幅は単一レンズ・近軸・幾何光学の全支持幅。FWHMでも収差を含む幅でもない。
```text
Φ = (n-1)/R
幅 ≈ (Q/A)×LED水平幅 + (p×開口率/c)×|1+Q/A-QΦ|
```

## 位相間隔をそろえる候補

- スクリーン1.5mm固定：LED→頂点 **134.837967mm**。
- LED→頂点125mm固定：スクリーン **1.390021mm**。
- 半径0.5mm・屈折率1.49のモデルの近軸最良結像位置：スクリーン **1.532989mm**。
- 位相間隔がそろう位置と、像が最も細くなる位置は同じとは限らない。
- ユーザー指定の空気中焦点距離は1.023mm。現行球面モデルのR/(n-1)は1.020408mmで一致していない。上記幅・焦点は現行モデルによる。
- 位相間隔をそろえる幾何計算はRに依存しないが、収差・像幅はRや非球面形状に依存する。
- 比較用configs/matched_distance_235normal.jsonとmatched_screen_235normal.jsonを用意。既定設定を自動でこれらへ変更はしない。

## 仕切り

- 直角方向の厚み1.5mm、高さ32mm。LED中心からの幾何的な通過半角は約18.970度。
- 同位相光源の中間位置に向かう光線を最初の仕切りで遮る単純直線モデル（屈折なし）：
  - 点光源：約29.255mm。
  - LED水平幅3mmを含む光源端の光線：約32.069mm。
- 32mmはこの単純モデルでも境界付近。遮光の余裕があるとは言えない。これは像の完全非重複や散乱ゼロの証明ではない。
- 実機の厚みの測定方向、発光面からの高さ、造形丸み・反射を確認する。

## 開口マスク

- レンズピッチ・傾きは変更しないので、開口40%のマスク寸法は変更なし。
- 溝に直角：開口0.28mm、遮光0.42mm、谷から片側遮光0.21mm。
- 水平換算：開口0.295146mm、遮光0.442719mm、谷スタート初期遮光0.221359mm、マスク周期0.737865mm。
- マスクの周期0.737865mmとスクリーン照射縞周期0.743839mmは異なる平面での値。混同しない。

## 解釈の限界

上記は幾何学的な再計算。液晶走査・応答、USB同期、実スクリーンの散乱、仕切りの反射、実機の追加アクリル、眼位置は含まない。クロストーク率は計算していない。
新しい寸法でMitsuba描画も実行し、結果の設定は各出力フォルダのconfig_used.jsonへ記録する。512 sppの単回描画は収束確認ではない。
