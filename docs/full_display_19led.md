# 全画面・19本LEDモデル

| 項目 | 設定 |
|---|---|
| 受光面 | 546×312mm、x±273・y±156mm |
| レンズ外形 | 同じ546×312mmの矩形。斜めの大きな平行四辺形ではない |
| レンズサンプリング | 900周期の格子を矩形外形で切断、1周期128分割 |
| LED | 19本連続、横中心間隔24.771175mm、直角間隔23.5mm |
| 配置原点 | 中央（10本目）のLEDのy=0での発光中心 |
| 最左・最右のy=0水平位置 | −222.940575mm、＋222.940575mm |
| 位相 | 左から0/1/2/3の繰返しを仮定。5/5/5/4本 |
| LEDの長さ | 328.876877mmを仮定（縦方向312mmを覆う長さ） |
| LED幅 | 水平方向3mm |
| LED→レンズ先端 | 138.13mm |
| LED側追加アクリル | 10mm、同一屈折率で密着 |
| レンズ先端→受光面 | 1.5mm、PMMA内 |
| 仕切り | 高さ32mm、厚さ1.5mm。バーと同じ長さ |
| 比較 | 仕切りあり／仕切り＋中心40%開口 |

LEDの実寸長と開始位相はユーザーから未指定。`led_array.bar_length_mm`と`first_phase`を実機に合わせて変更する。長さは発光するバー全体の長さであり、上下分割制御はこの静的な照射シミュレーションでは再現していない。

19本の場合は4位相を同数にできない。全体の平均強度差には本数差や端の遮光も含まれる。中心4本を原点にしていた旧16本モデルとは原点の定義も異なる。新しい`led_layout.json`を参照する。

## 解像度

| 設定 | 画素数 | 水平・垂直の画素幅 | 用途 |
|---|---|---|---|
| current.json preview | 2184×1248 | 0.25mm | 全体の照射範囲・大きな欠けを確認 |
| current.json quality | 4368×2496 | 0.125mm | 全体を細かく見るが、細い像幅の測定には不十分 |
| full_display_fine.json | 17472×9984 | 0.03125mm | 以前のプレビューと同じ画素密度。約0.03mmの像幅の高精度評価にはなお不十分 |

既定プレビューは約0.74mm周期に約3画素しかなく、縞の幅・ピーク位置・重なりの定量評価に使わない。細い縞はエイリアシングで見え方が変わり得る。高精度な像幅評価は全体画像とは別の局所高解像度モデルで行う。

fineの1枚のfloat32配列は約0.70GB。8条件のNPYだけで約5.58GB。RGB描画、プロット、4位相合成などは追加のRAMを必要とする。条件を限定して先に動作を確認する。

## レンズ外形

レンズの各溝直角座標uに対し、world x/yの矩形との交点から溝軸方向の上下端を決める。追加PMMAは同じ矩形でレンズの底面へ一体化。外形の頂点だけは数値的なゼロ面積を避けるため0.1µm内側に置く。

実LED配光、反射・散乱、実スクリーンの散乱、LCD、観察者、時分割同期は未モデル化。全画面にしただけで実機クロストークを算出できるわけではない。
