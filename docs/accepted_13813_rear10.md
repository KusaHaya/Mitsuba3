# 採用設計：LED→頂点138.13mm・LED側PMMA10mm

## 設定

| 項目 | 値 |
|---|---:|
| LED→凸面頂点 | 138.13mm |
| LED側の追加PMMA（平面側に密着） | 10mm |
| レンズ基材厚（追加PMMAとは別） | 2mm |
| 凸面頂点→スクリーン | 1.5mm、PMMA内 |
| LEDピッチ | 23.5mm直角、24.771175mm水平 |
| レンズピッチ | 0.7mm直角 |
| 傾き | 縦:横=3:1 |
| LED水平幅 | 3mm |
| 開口マスク | 中心40% |
| 仕切り | 高さ32mm、厚み1.5mm（変更なし） |
| 光源・ROI | 16本、4本/位相、水平±35mm・上下±4mm |

## 形状と換算

同一屈折率で密着した平面側PMMAをレンズ基材と一体化。凸面頂点z=0、元の平面z=-2mm、追加板の底面z=-12mm、LED z=-138.13mm、スクリーンz=+1.5mm。メッシュは底面だけ延長し、凸面や溝を変えない。板間の微小空隙・接着層は含まない。

```text
A = D - t + t/n - T(1-1/n)
Q = s/n
P水平 = 0.7(1+Q/A)/(3/√10)
Δ水平 = (Q/A)×24.771175
```

138.13mmは近軸上の一致距離138.126558mmを丸めた値。幾何的な位相間隔の一致は、収差・液晶応答・視域・クロストークの保証ではない。

## 幅の近軸参考値

- マスクなし：0.037948mm。
- 中心40%開口：0.028683mm。
- 全支持幅の近軸推定。FWHMや実描画で測った幅ではない。球面モデルのR=0.5mm、n=1.49による。ユーザー指定焦点距離1.023mmと、モデルのR/(n-1)=1.020408mmには小差がある。

## 仕切りについて

- 32mmを維持して比較する。追加PMMAを無視した単純直線計算の同位相中間点遮光高さは、点光源32.328mm、光源幅を含む場合35.438mm。
- これらは屈折を省いた参考値であり、32mmで漏れゼロとは主張しない。現在の設計でMitsubaの遮光を確認する。

## 実行

```powershell
git pull
.\.venv\Scripts\python.exe simulate.py --variant scalar_rgb --spp 512
```

受光面の照射分布を計算するモデル。実LCD、液晶応答、USB同期、実スクリーンの散乱、仕切り反射は含まない。画像の重なり指標は実機クロストーク率ではない。512spp単回は収束確認ではない。

スクリーン位置別の再計算は`python recalculate_design.py`。`design_recalculated/screen_sweep.csv`と`summary.json`はcurrent.jsonの現在値を反映する。
